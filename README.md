# mb_webhook

A lightweight webhook service for handling incoming HTTP requests and processing payloads.

This project is in its early stage of development. The goal is to provide a simple, extensible foundation for receiving webhook events, validating payloads, and passing them to downstream processing.

## Status

- Early-stage prototype
- Active development
- Intended for experimentation and iteration

## Goals

- Receive webhook payloads over HTTP
- Validate and inspect incoming requests
- Route events to internal processing logic
- Keep the project simple and easy to extend

## Getting started

1. Clone the repository
2. Open the solution in your preferred .NET environment
3. Build the project
4. Configure your environment variables or app settings
5. Run the service and test webhook delivery
